# FR Voice Tutor — Stage 3 + Перевод

Теперь приложение поддерживает базовый перевод FR ⇄ RU.

Что добавлено
- UI для перевода текста (можно вставить текст и перевести из/в французский и русский).
- Автоматический перевод распознанного французского текста (после записи) — перевод показывается в блоке "Перевод (FR → RU)".
- Serverless proxy `/api/translate` для LibreTranslate (используется при деплое на Vercel) — это решает проблему CORS.

Как это работает
- На проде (Vercel) клиент вызывает `/api/translate`, а Vercel функция пересылает запрос на https://libretranslate.de/translate и возвращает результат.
- На локальном режиме (при разработке) клиент пытается сначала обратиться к `/api/translate` (рабочий при `vercel dev`), а затем как fallback — напрямую к `https://libretranslate.de/translate` (иногда может блокироваться CORS в браузере).

Инструкция по использованию
- Запиши фразу на французском (кнопка "Говорить") — после распознавания текст автоматически проверяется и переводится на русский.
- Перейди в блок "Перевод текста" чтобы вручную перевести любой текст между FR и RU.

Если перевод иногда не работает локально — задеплой на Vercel или используй `vercel dev`.
