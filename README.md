# FR Voice Tutor — Stage 3

Третья версия прототипа: добавлены режимы "Практика" и "Урок", шаблоны фраз, уроки, история и экспорт данных.

Что нового в Stage 3
- Режим уроков: учитель задаёт фразу, ты отвечаешь, приложение проверяет и оценивает.
- История практики с возможностью экспорта (JSON).
- Серверless proxy для LanguageTool (api/languagetool.js) — чтобы избежать CORS при развертывании на Vercel.

Как запустить локально

1) Установи Node.js 18+ и npm
2) Клонируй репозиторий
   git clone https://github.com/gochatsulaia/fr-voice-tutor-mvp.git
3) Установи зависимости
   cd fr-voice-tutor-mvp
   npm install
4) Запусти в режиме разработки
   npm run dev

Примечание по LanguageTool и CORS
- При локальном запуске `npm run dev` браузер может блокировать прямые запросы на api.languagetool.org из-за CORS.
- Для теста локально можешь либо:
  - использовать прямой вызов (иногда работает), либо
  - установить Vercel CLI и запустить `vercel dev` (он будет проксировать API-роуты в `/api`) — тогда запросы к `/api/languagetool` будут работать локально.

Развёртывание на Vercel (рекомендуется для простого и бесплатного live-demo)

1) Создай аккаунт на https://vercel.com и подключи GitHub (разреши доступ к репозиторию fr-voice-tutor-mvp).
2) Нажми "Import Project" → выбери репозиторий fr-voice-tutor-mvp → Deploy.
3) Vercel автоматически соберёт проект (Vite) и задеплоит статический фронтенд + serverless функцию `/api/languagetool`.

Или используя Vercel CLI:

1) Установи CLI: npm i -g vercel
2) В корне проекта запусти: vercel login
3) Затем: vercel --prod

После развёртывания приложение будет доступно по ссылке, которую даст Vercel.
