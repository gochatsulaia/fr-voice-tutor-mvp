# FR Voice Tutor — MVP

Простой веб‑прототип для практики французской речи (MVP). Всё бесплатно: распознавание — через браузер (Web Speech API), корректировка — через LanguageTool public API, озвучивание — Web Speech Synthesis.

Особенности:
- Кнопка «Говорить» (fr-FR) — запись 5–15 секунд
- Показ распознанного текста (ASR)
- Отправка в LanguageTool — исправления и подсказки
- Прослушивание исправленного варианта (TTS)
- Простая подсветка отличий и кнопка «Поделиться»

Как запустить локально

1) Установи Node.js (рекомендуется 18+) и npm
2) Клонируй репозиторий:
   git clone https://github.com/gochatsulaia/fr-voice-tutor-mvp.git
3) Установи зависимости:
   cd fr-voice-tutor-mvp
   npm install
4) Запусти приложение в режиме разработки:
   npm run dev
5) Открой браузер по адресу, который выведет Vite (обычно http://localhost:5173)

Примечания и отладка
- Web Speech API работает не во всех браузерах; для наилучшего результата используй Chrome/Edge на десктопе или Android.
- LanguageTool public API может иметь лимиты и CORS-политику; если при проверке возникают ошибки, см. раздел "Если LanguageTool блокирует запросы" ниже.

Если LanguageTool блокирует запросы (CORS или лимиты)
- Для MVP можно развернуть небольшой proxy-сервер (serverless) который будет делать запросы к LanguageTool без CORS проблем.
- Простой proxy на Node (Express) можно запустить на Render/Heroku/Cloudflare Workers. В будущем я добавлю инструкции и пример кода для proxy.
