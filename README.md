# FR Voice Tutor — второй этап

Это улучшенная версия MVP-приложения для практики французского языка.

Что добавлено по сравнению с первым вариантом:
- более удобный UI и современный дизайн;
- подборка готовых фраз и темы для практики;
- карточка «ИИ-советник» с полезными рекомендациями;
- история практики и статистика по тренировкам;
- подписка по email (с сохранением в localStorage);
- улучшенная разметка “что сказал / что исправлено”;
- кнопка «прослушать» для исправленной фразы.

Технологии:
- React + Vite
- Web Speech API (распознавание речи)
- Web Speech Synthesis (озвучивание)
- LanguageTool public API (коррекция текста)

Как запустить локально:
1. Установи Node.js 18+
2. Клонируй репозиторий:
   git clone https://github.com/gochatsulaia/fr-voice-tutor-mvp.git
3. Перейди в проект:
   cd fr-voice-tutor-mvp
4. Установи зависимости:
   npm install
5. Запусти приложение:
   npm run dev
6. Открой браузер по адресу, который покажет Vite (обычно http://localhost:5173)

Маленькая важная ремарка:
- Web Speech API работает лучше всего в Chrome и Edge.
- LanguageTool public API может иметь ограничения на уровне CORS/лимитов, поэтому для коммерческого проекта желательно добавить маленький backend proxy.
